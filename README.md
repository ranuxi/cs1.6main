# CS 1.6 Craft

Counter-Strike 1.6 в выживании Minecraft 1.21.11 (Fabric). Мир остаётся майнкрафтовским, а руки, оружие, стрельба, закупка, деньги и HUD — из Counter-Strike 1.6, причём модели, звуки и спрайты читаются **из вашей установленной CS 1.6** во время игры. В этом репозитории нет ни одного файла Counter-Strike.

## Что есть

- Настоящие руки и оружие CS 1.6 от первого лица (модели `v_*.mdl`) с их анимациями, звуками и вспышками выстрела. Старт: нож и USP.
- 24 ствола CS 1.6, нож (удар / укол, x3 со спины), гранаты HE, флешка, дым, кевлар и шлем.
- Стрельба по правилам CS: разброс от стойки и очереди, отдача (view punch), скорострельность, падение урона по дистанции, хедшоты x4, автоматический огонь.
- Закупка в любом месте на **B**: цены, деньги, отдельные патроны под каждый тип оружия, быстрые покупки **,** и **.**.
- Деньги (за убийства, пережитую ночь, достижения, редкие руды) и отдельный опыт с уровнями, которые открывают оружие.
- **F6** переключает интерфейс CS 1.6 ↔ Minecraft без потери денег, опыта, инвентаря, оружия и патронов.

Управление: ЛКМ огонь, ПКМ укол/прицел, R перезарядка, F осмотр, B закупка, 1–4 слоты, 5 прошлое оружие, колесо мыши смена оружия.

## Установка вручную

1. Minecraft: Java Edition и Counter-Strike 1.6 (Steam) на этом ПК.
2. [Fabric Loader](https://fabricmc.net/use/installer/) для 1.21.11.
3. Положить `cshudcraft-1.0.0.jar` и `fabric-api-0.141.6+1.21.11.jar` (из архива релиза) в `%APPDATA%\.minecraft\mods`.
4. Запустить профиль `fabric-loader-1.21.11`.

Путь к CS находится сам (библиотеки Steam) или задаётся в `%LOCALAPPDATA%\CSHudCraft\cshudcraft.properties` строкой `cs_dir=...`.

## Сборка

```
gradlew build
```
Нужен JDK 21. Готовый мод: `build/libs/cshudcraft-1.0.0.jar`.

Вся настройка оружия, патронов, цен и наград — в таблицах `sheets/*.json` (они же упаковываются в мод).
